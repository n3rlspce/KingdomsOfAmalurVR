## OpenXR runtime

Both the native and WOW6432Node OpenXR registry branches currently select VDXR. The 32-bit branch points to:

`C:\Program Files\Virtual Desktop Streamer\OpenXR\virtualdesktop-openxr-32.json`

That manifest resolves `virtualdesktop-openxr-32.dll` in the same folder. Runtime PE details are recorded in [vdxr-pe-baseline.json](vdxr-pe-baseline.json). Registry presence and a matching DLL are prerequisites, not proof that session creation succeeds with a connected headset.

## Architectural consequences

1. Build the injected mod and its in-process native dependencies for **Win32/x86**, including the OpenXR loader. The operating system's 64-bit requirement did not imply a 64-bit game executable.
2. Keep the D3D11 plan. Use a native D3D11 OpenXR binding if the live device satisfies runtime graphics requirements.
3. MGS5VR remains a useful D3D11/OpenXR implementation reference, but its pointer-size assumptions and game-specific integration must be audited before any reuse. A matching graphics API does not establish 32-bit portability.
4. Recovered Witcher 2 x86 OpenXR/VDXR work is especially relevant for loader, ABI, and lifecycle patterns. Its D3D9-to-D3D11 bridge is not needed merely because this game is x86.
5. Verify **32-bit availability** of Meta XR Operator and Simulator before planning in-process automation. An x64-only API-layer DLL cannot load inside this game. If unavailable, use a separate test harness or our own diagnostics; do not make this tooling a blocker for conversion.
6. Include 32-bit address-space pressure in performance planning. Avoid retaining unnecessary eye copies, capture buffers, and extracted asset caches in-process.

## Next bounded experiment

Build an x86 D3D11/OpenXR smoke-test application: create a VDXR session, render two distinct eye views, enumerate controller actions, and log selected adapter, feature level, session transitions and timing. Establish this independently before introducing game hooks. Then capture the unmodified game's actual device and frame layout and begin camera discovery.
