# README artwork

The [README banner](amalur-vr-hero.png) is a fan-made adaptation for this unofficial VR mod, not an official VR release or a statement of publisher endorsement.

Source artwork and game trademarks belong to their respective owners. The source key art and logo were obtained from the [official Kingdoms of Amalur: Re-Reckoning website](https://kingdomsofamalur.thqnordic.com/US/ps4):

- [Official key art](https://kingdomsofamalur.thqnordic.com/game-sites/kingdomsofamalur/content/keyart.png)
- [Official logo](https://kingdomsofamalur.thqnordic.com/core/logos/amalur-rereckoning_logo.png)

The banner was composited and adapted with the built-in image-generation tool, adding matching gold “VR” lettering. It is promotional artwork, not a gameplay screenshot. The original assets are not claimed as project-owned artwork or relicensed by this repository.

No extra text, no tagline, no publisher logo, no headset, no controllers, no neon, no UI, no frame, no modern sans-serif letters, no other new objects.
